# Tmoh V14 — المرحلة 1 (طبقة إضافية فوق المشروع الحالي)

## الملفات
- `tmoh-v14.js` و`tmoh-v14.css`: القائمة بستة أقسام + الرئيسية + المذاكرة + ChatBook + التحفيز + رحلتي وتقدمي + أدوات أخرى.
- `sw.js`: نسخة معدّلة (أضفت الملفين للكاش ورفعت رقم النسخة فقط).

## الدمج (index.html لم يصلني، فالتعديل عليكِ — سطران)
1. في `<head>` بعد آخر ملف CSS: `<link rel="stylesheet" href="tmoh-v14.css">`
2. قبل `</body>` **بعد كل ملفات JS الأخرى** (آخر سطر): `<script src="tmoh-v14.js"></script>`
3. استبدلي `sw.js` بالنسخة المرفقة.

## ما لا يتغير
مفتاح `tmoh2` وبنية الملف الشخصي، رابط الـ Worker (`CONFIG.AI_URL`)، وكل الصفحات القديمة (متاحة من «أدوات أخرى ← صفحات الأدوات القديمة»).
البيانات الجديدة تُخزَّن فقط تحت `d.tm14` (إضافي، يتجاهله الكود القديم).

## كيف تعمل
- القائمة: 6 أزرار فقط تستبدل القائمة القديمة بعد الدخول؛ الصفحات القديمة تبقى بروابطها، والقسم الأب يُظلَّل.
- المذاكرة: تختارين المادة ثم الدرس مرة واحدة، وتُزامَن مع `d.tmohTools` فتستخدمها أدوات الدرس الموجودة (لخّصلي/اشرحلي/امتحان/أخطاء)، والعدّاد يأخذ المادة والدرس، وكلها تعتمد على `flow.js` للراحة.
- كل الأرقام تُحسب من `d.sessions` و`d.tasks` و`d.done` و`d.studyV1` و`d.mistakes` و`d.exams`، ومجموع «سجل النقاط» = `xp()` تمامًا.
